## Streets of Rage Remake para Android — v1.1

**Novedades**

- **El lanzador encuentra el juego en más consolas** (por ejemplo, RG Arc con GammaOS):
  - Busca solo la carpeta con `SorR.dat` en la memoria interna y en la tarjeta SD.
  - Entiende las carpetas que devuelven los distintos selectores del sistema.
  - Si eliges una carpeta que tiene el juego dentro de una subcarpeta, también vale.
  - Nuevo botón **Escribir la ruta**, por si el selector de carpetas no funciona.
  - Si no encuentra el juego, explica por qué: la carpeta no existe, el sistema no deja leerla o falta `SorR.dat`.
- **Optimización**:
  - El juego ya no escribe en la tarjeta mientras juegas.
  - Los controles táctiles y el stick no generan basura en memoria en cada movimiento.
  - El lanzador gasta menos memoria en pantallas pequeñas.
  - Librerías más ligeras.

Se instala encima de la v1.0 / v10.x sin desinstalar.

---

**What's new (English)**

- The launcher finds the game on more devices (e.g. RG Arc with GammaOS):
  - It searches internal storage and SD cards automatically.
  - It understands more folder pickers and also accepts a folder with the game in a subfolder.
  - New **Type the path** button.
  - Clearer messages when the data is missing.
- Optimisations:
  - No SD card writes while playing.
  - No garbage generated by touch or stick input.
  - Lower launcher memory use on small screens.
  - Smaller native libraries.

Installs over v1.0 / v10.x.
